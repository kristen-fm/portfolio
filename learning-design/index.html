Code Review Anxiety Workbook

The Code Review Anxiety Workbook is a free, self-guided resource that helps software developers recognize and manage the anxiety many experience while giving and receiving code reviews. Dr. Carol Lee and I adapted an empirically tested, 90-minute workshop intervention (Lee et al., 2024) into a self-paced workbook that individuals or teams can work through on their own or in a “workbook club.”

Grounded in decades of cognitive-behavioral research on anxiety, the workbook guides readers through strategies for managing physiological stress responses and through cognitive restructuring: identifying, challenging, and reframing anxious thoughts to be more realistic and self-compassionate.

I include the workbook here because it represents evidence-based learning design in an authentic workplace context, as my co-author and I translated an empirically tested, facilitated intervention into an accessible, self-directed learning experience. It also embodies my commitment to freely sharing research findings and interventions in ways that benefit relevant learning communities.

Reference

Lee, C. S., Hicks, C. M., & Foster-Marks, K. L. (2024). “My code is shit”: Negative automatic thoughts and outcomes of a behavioral experiment for code review anxiety. PsyArXiv. https://doi.org/10.31234/osf.io/hz3et
